# lukasboehnert.com

Personal research website, built with GitHub Pages and the Minimal theme.

## Where things live

| File | What it controls |
|---|---|
| `index.md` | Main page: bio, papers, abstracts |
| `_config.yml` | Left column: name, photo, title, CV/Email/Twitter/LinkedIn links |
| `assets/css/style.scss` | Small style tweaks on top of the theme |
| `photo.jpg` | Profile photo |
| `*.pdf` | CV, JMP, slides (linked as `/FILENAME.pdf`) |

## Updating the site

1. Edit the files in VS Code (e.g. copy a `<div class="paper">` block in `index.md` to add a paper).
2. Replace a PDF by saving the new version over the old one with the same filename.
3. In VS Code's Source Control panel: write a short message, click **Commit**, then **Sync/Push**.
4. The live site updates about a minute later.
